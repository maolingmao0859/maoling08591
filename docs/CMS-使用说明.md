# MR.CAT 内容管理使用说明

## 日常编辑

网站负责人完成部署并为你创建管理员后，在「网站域名/admin」登录。若前台放在 Vercel，这个地址会跳转到独立后台。本站不开放账号注册，普通访客没有编辑权限。

- **网站设置**：修改姓名、个人简介、邮箱、微信、首页文案、人物、背景视频、视频封面和纪实照片。新图片优先使用「首页与个人图片 / 视频」的上传按钮；旧图片路径主要用于迁移和保留原素材，不必手动填写。
- **作品管理**：点击项目名称编辑。可新增作品、换封面、修改中英文名称、介绍、项目状态、地点、年份、面积和角色。尚未确认的信息继续填写「待确认」。
- **详情图片**：新增一行，上传或从素材库选择图片，填写图片说明和类型。拖动行左侧手柄调整顺序。真实现场照片、效果图和总平面图分别标注。
- **Journal 手记**：编辑栏目标题、正文、图片和顺序。
- **图片与视频**：集中管理素材。不要删除仍被项目使用的图片；先替换项目引用再删除。

作品和手记的「展示顺序」数字越小越靠前。详情图片按拖动后的行顺序展示。图片说明用于读屏与图片无法显示时的提示，建议简短说明画面内容。

## 草稿、预览与发布

1. 修改后点击「保存草稿」。公开网站保持已发布版本。
2. 网站设置或作品编辑页点击「预览」（或后台首页的草稿预览链接）。只有登录的管理员可以查看草稿。
3. 检查桌面与手机效果，确认后点击「发布 / 发布修改」。公开网站会在下一次加载时更新，无需每次提交 GitHub。

后台负责内容；固定排版和动画由原网站控制。因此不需要学习页面布局工具，也不会因换图或改字破坏整站风格。标题较长或图片构图差异较大时，发布前应检查手机预览。

## 图片和视频建议

人物使用透明 PNG/WebP。项目照片建议提供清晰 JPEG/PNG/WebP；后台自动生成网页尺寸。总平面图按完整比例展示，图片放大支持 Esc 关闭和键盘左右切换。背景视频使用兼容浏览器的 MP4，上传前建议压缩；最大单文件 50 MB，仍需遵守部署平台限制。背景默认静音循环，reduced-motion 下显示封面。

## 密码与维护

不要共享管理员密码。初始账号由负责人在服务器创建；之后可在后台管理账号。暂未配置邮件服务，因此「忘记密码」不能发送重置邮件，请联系负责人进行密码重置。没有购买任何付费服务。

图片素材库中的文件是网站公开素材，不是私密文件保险箱：知道文件地址的人可以查看。草稿文字及修改权限受管理员保护，未发布项目不会出现在公开作品列表。

## 当前状态

现有四个作品、手记、首屏人物和视频会通过初始化脚本导入，重复运行不会覆盖已编辑内容。此前大于 32 MiB 的项目压缩包仍未导入；新增后台后可通过素材上传按钮逐张接入真实项目图片。
